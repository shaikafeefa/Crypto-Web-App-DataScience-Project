# Crypto Web App

A Cryptocurrency Analytics Web Application built using Python and Streamlit that provides real-time cryptocurrency market analysis and visualization.

## Description
Built a Cryptocurrency Analytics Web App using Python and Streamlit to analyze real-time crypto market data with interactive charts, price trends, market capitalization analysis, and downloadable reports using APIs, Pandas, and Matplotlib.

## Features
- Real-time cryptocurrency price tracking
- Interactive charts and graphs
- Market capitalization analysis
- Historical price trend visualization
- CSV data download option
- User-friendly dashboard

## Technologies Used
- Python
- Streamlit
- Pandas
- Matplotlib
- Requests
- CryptoCMD

## Installation

## Installation

Clone the repository:

```bash
git clone https://github.com/shaikafeefa/Crypto-Web-App-DataScience-Project.git
```

Navigate to the project folder:

```bash
cd Crypto-Web-App-DataScience-Project
```

Navigate to the project folder:

```bash
cd DSProject
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run crypto_price_app.py
```
